# ⚡ Email Setup - Quick Start (2 Minutes)

## Your Gmail: rahulpadole43@gmail.com

✅ Messages sent to your Gmail
❌ Messages NOT shown on website

## What You Need
- Gmail account (you have: rahulpadole43@gmail.com)
- 2-Factor Authentication enabled

## Step 1: Enable 2FA (1 minute)
```
Go to: https://myaccount.google.com/security
Find: 2-Step Verification
Enable it (confirm with phone)
```

## Step 2: Get App Password (1 minute)
```
Go to: https://myaccount.google.com/apppasswords
Select: Mail + Windows Computer
Copy: 16 characters (abcdefghijklmnop)
```

## Step 3: Update .env (30 seconds)
Edit `backend/.env`:
```
EMAIL_PASSWORD=abcdefghijklmnop
```

## Step 4: Restart Backend (30 seconds)
```bash
cd backend
npm run dev
```

## Step 5: Test! ✅
```
1. Open http://localhost:5173
2. Click Chat button (bottom-right)
3. Submit form
4. Check rahulpadole43@gmail.com inbox
5. You get the email!
```
